# Textbook ink with selective color
Precise dark pen-and-ink linework on white; typeset serif mathematics; sparse controlled hatch. No fake aging, roughened accuracy, sketch fonts, glossy spheres, decorative bundle planes, or universal rounded cards. Constructed 3D line drawings where depth matters; flat connectivity where only labels/bonds matter. Hatching can indicate geometry or set membership, but not both ambiguously in one panel. Color when hatch cannot carry distinctions cleanly.
Palette defaults: H white/dark outline; C30363B; N436E9B; OB44C59; K716191; RbA27B24. These are proposed restrained choices, not a universal element standard. Mathematical accents borrow colors; within each figure each color has one meaning. Keep meanings stable along a logical thread; local reassignment allowed across unrelated figures. Label semantics and grayscale redundancy.
Prototype at actual manuscript width (initial150mm), 9pt labels (minimum8pt), .65pt main contours, .35pt sufficiently dark guides, .8pt operations. Adjust through render review; no after-the-fact shrinking of oversized artwork. No fixed panel count/aspect ratio. Keep text off hatch and boundaries.
Atoms projected from explicit centered coordinates with declared masses/isotopes, same camera for comparisons, depth-derived occlusion. Do not invent chemical bonds or meaningful barriers. Glyph size not molecular coordinate. Every arrow means a declared action/path/projection/identification/transition/transform. Group inclusion normally undirected. Hatches, dashes and arrow styles documented per panel.
