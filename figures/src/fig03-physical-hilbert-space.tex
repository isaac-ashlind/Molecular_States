% Figure 3. Physical Hilbert space. What the reader must see: a relabeling moves the digits and leaves the spins
% with the places, so the value at the relabeled configuration is the permuted spin value times the statistics
% sign; inversion sends every column through the origin and costs the parity sign instead. Drawing: the top row is
% the configuration story, X, sigma X = X P_sigma and E* sigma X = -X P_sigma, with spin arrows beside the nuclei and
% digits inside the hydrogens; Psi carries each configuration down to its value in the spin space, the bottom row,
% where the same two arrows act again: sigma permutes the two slots and brings chi_stat(sigma), E* leaves the slots
% and brings chi_pm. Colors: oxygen red; the spin arrows and everything else ink. Hatch unused. Planar water:
% -X P_sigma is also a rotated copy (caption).

  \end{scope}}
