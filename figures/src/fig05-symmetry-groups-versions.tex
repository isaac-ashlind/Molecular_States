% Figure 5. Symmetry groups and versions. What the reader must see: (A) methylamine as two fragments, the reference
% X0 with its half-turn axis, and bX0 = X0 P_b drawn solid with digits: the half-turn reproduces it, so H = {E, b};
% the mirror plane seen edge-on down the C-N axis; (B) the feasible regime carved from the whole interval [H, S]
% (36 subgroups, grey) to the bond interval [H, B] (10 subgroups, black) with the chain H < G6 < G12 < B in blue;
% in the bond interval every node is named by its generators and every cover is labelled by the generator it adds,
% so the climb reads as generators being adjoined; (C) versions are the same positions with the digits moved by g.
% Colours: gold = the chain (a halo under the styled covers); covers by generator in the line grammar, solid t,
% dashed u, dotted a starred generator; blue = nitrogen. Hatch unused. All lattice data, generator forms and cover labels computed
% (compute/groups.py, compute/make_data.py, checks/verify.g); digits inside the hydrogens are the column labels.
