# Quantum state spaces of nonrigid molecules: manuscript and figure suite

The manuscript (`docs/manuscript.tex`) and its fourteen plates: a cover guide, twelve numbered plates (one per
section) and an unnumbered closing plate. The plates are standalone TikZ documents drawn from computed, independently
checked data. Start with `HANDOFF.md`.

## Build
```
python3 build.py              # data -> checks -> plates -> previews -> proofs -> manuscript (build/manuscript.pdf)
python3 build.py --only 06    # one plate (data and checks still run)
```
A failing check stops the build. Requires TeX Live (pdflatex, bibtex, pgf/TikZ, pgfplots, standalone, titlesec),
Python 3 with numpy, and poppler (pdftoppm, pdftotext). SymPy, GAP and Ghostscript are optional cross-checks and the
grayscale proof; the build says when it skips them.

## Layout
```
docs/manuscript.tex         the manuscript; refs.bib its bibliography
figures/src/figNN-*.tex     one standalone document per plate (fig00 the cover guide, fig13 the closing plate)
figures/shared/             figurestyle.sty (palette, plate style) and primitives.tex (line styles, atoms, rods,
                            tube, band, hatch, zoom bubble): the whole visual vocabulary
figures/data/               generated by compute/make_data.py: numbers.tex, molecules.tex, *.dat, summary.json
figures/pdf/                the compiled plates the manuscript includes
figures/png/                the same plates at 600 dpi (high-resolution raster copies)
figures/preamble.tex        the preamble lines another document needs to include the plates
compute/                    geometry.py, groups.py, make_data.py (every coordinate and number on the plates)
checks/                     verify.py, verify_symbolic.py, verify.g (GAP), verify_spin.py, verify_antiprism.py,
                            verify_methane.py, collisions.py (text overlaps), cvd_preview.py (colour-vision preview)
scaffold/                   outline.tex (figure numbering check), proofsheet.tex (print-scale proof and squint sheet)
docs/                       style.md (the rules), author-decisions.md, caption-notes.md (per-plate disclosures),
                            verification.md, storyline.md; history/ (plans and logs, for reference)
reference/                  the author's materials: the manuscript export, the original handoff package, plate scans
build.py                    the one entry point
```

## Using the plates elsewhere
Copy `figures/pdf/` into the other project, add the lines of `figures/preamble.tex`, and place each plate with
`\includegraphics[width=\linewidth]{figNN-name}`. Every plate is 15.2 cm wide and meant to be included at
`\linewidth`, so all of them print at one scale. To recompile a plate elsewhere, take `figures/src/figNN-*.tex`,
`figures/shared/*` and `figures/data/*`; each plate compiles alone with pdflatex.
