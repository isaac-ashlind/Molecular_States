# Molecular state space: the figure suite (v2)

Twelve numbered plates, one per section of the paper, and one unnumbered guide, drawn as standalone TikZ/PGF
plates in the manner of the ink plates of Harter (1993), from computed and verified data.

## Layout
```
figures/src/figNN-*.tex     one standalone document per plate (fig00 is the guide)
figures/shared/             figurestyle.sty (palette, styles), primitives.tex (atoms, rods, tube, band, zoom)
figures/data/               molecules.tex, numbers.tex, *.dat, summary.json   (generated by compute/make_data.py)
figures/pdf/                the compiled plates, the deliverable to drop into the manuscript
figures/preamble.tex        the three preamble lines a manuscript needs
compute/                    geometry.py, groups.py, make_data.py            (stdlib only)
checks/                     verify.py (stdlib), verify_symbolic.py (SymPy), verify.g (GAP), collisions.py
scaffold/                   outline.tex (numbering check), proofsheet.tex (print-scale proofs and squint sheet)
studies/                    calibration and alternative studies (not part of the deliverable)
docs/                       PLAN-v2.md, caption-notes.md, verification.md, author-decisions.md, style.md,
                            illustration-notes.md, integration.patch, worklog.md
reference/                  the manuscript export, the handoff package and the author's plate scans
build.py                    data -> checks -> plates -> previews -> numbering check -> proofs -> collision report
```

## Build
```
python3 build.py              # everything; stops on any failing check
python3 build.py --only 06    # one plate
```
Tested with: TeX Live 2023 (pdflatex, pgf 3.1.10, pgfplots 1.18, standalone), Python 3.11, SymPy 1.14,
GAP 4.12.1, poppler (pdftoppm, pdftotext), Ghostscript (grayscale proof). SymPy and GAP are optional cross-checks;
the stdlib checks always run.

## Porting to Overleaf
1. Copy `figures/pdf/` into the project and add the lines of `figures/preamble.tex` to the preamble.
2. Place each plate with `\includegraphics[width=\linewidth]{figNN-name}`. To compile the reorganized manuscript with
   its references, from the repository root:

       mkdir -p build/ms && pdflatex -output-directory build/ms docs/manuscript-reorganized.tex
       (cd build/ms && BIBINPUTS=../../docs: bibtex manuscript-reorganized)
       pdflatex -output-directory build/ms docs/manuscript-reorganized.tex   # twice
 `docs/manuscript-reorganized.tex` is
   the export with the sections reordered to the figure flow and every plate placed (text moved verbatim);
   `docs/integration.patch` is the same as a diff from the export.
3. To recompile a plate inside Overleaf instead, upload `figures/src/figNN-*.tex`, `figures/shared/*` and
   `figures/data/*` and compile that file with pdflatex; each plate is a `standalone` document.
