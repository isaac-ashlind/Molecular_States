# History

Records of how the suite was built, kept for reference. None of them is needed to build or finish the manuscript;
the current rules are in `docs/style.md`, the decisions in `docs/author-decisions.md`, the per-figure disclosures in
`docs/caption-notes.md`, and the hand-off in `HANDOFF.md`.

| File | What it records |
|---|---|
| `PLAN-v2.md`, `PLAN-v3.md` | the plans the suite was built from (2026-10-03, 2026-10-04) |
| `calibration-record.md` | the style calibration round and the restart plan of 2026-10-03 |
| `illustration-notes.md` | alternatives, critiques and choices, figure by figure |
| `notation-migration.md` | the notation migration of 2026-10-04 |
| `worklog.md` | the work log, session by session |
| `integration.patch` | an early diff from the author's export to the reorganized manuscript (superseded) |

The study sheets these records cite (`studies/`, with rounds 3 to 6 of alternatives) and the zip of the repository
(`dist/molecular-figures-v2.zip`) were removed from the tree on 2026-10-05. They remain in the git history up to
commit ba92480 and in the source backup delivered that day.
