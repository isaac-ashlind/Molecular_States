# Plate audit (read-only, step 4)

Scope: figures/shared/figurestyle.sty (`sty`), figures/shared/primitives.tex (`prim`), figures/src/figNN-*.tex (`figNN`).
Usage counts include figures/data/molecules.tex, since the generated pics call shared macros. Every claim below was checked against the code; computed values are marked "computed".
